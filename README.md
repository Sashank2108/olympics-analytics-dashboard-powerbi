# 🏅 Olympics Analytics Dashboard (Power BI)

An interactive Power BI dashboard built to explore historical Olympic data, focusing on athlete participation trends, medal distribution, and country-wise performance.

---

## 📊 Project Overview

This project analyzes Olympic athlete data to uncover insights about:

- Athlete participation over time
- Medal distribution by country
- Sport-wise medal contributions
- Gender-based medal patterns
- Age distribution of medal-winning athletes

The dashboard allows users to interactively explore the data using filters and slicers.

---

## 📂 Dataset

The project uses two datasets:

1. **dataset_olympics.csv**
   - Athlete information
   - Sport, event, year
   - Medal results

2. **noc_region.csv**
   - Mapping between NOC codes and countries

3. **Source** - https://mavenanalytics.io/data-playground/120-years-of-olympic-history
---

## 🧹 Data Processing

Data cleaning and preparation were performed using **Power Query**, including:

- Handling missing values
- Data type corrections
- Column profiling
- Dataset merging using NOC codes

---

## 📈 Key Visualizations

The dashboard includes:

- **KPI Cards**
  - Total medals
  - Gold, Silver, Bronze
  - Total athletes

- **Line Chart**
  - Athlete participation trends over time

- **Map Visualization**
  - Country-wise medal distribution

- **Sport Analysis**
  - Top sports contributing medals

- **Donut Chart**
  - Medal distribution among athletes

- **Age Distribution**
  - Age-wise medal trends

- **Top Athletes Table**
  - Athletes with highest medal counts

---

## 🎛 Interactive Features

Users can filter data using slicers:

- Year
- Country
- Sport
- Gender
- Season
- Medal type

## 📌 Key Insights

- Athlete participation has increased significantly over time.
- Countries like the United States and Russia dominate medal counts.
- Athletics and Swimming contribute the highest number of medals.
- Most medal-winning athletes fall within the 20–30 age range.
